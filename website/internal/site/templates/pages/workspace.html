Documentation / keyboard-first workflow

Workspace

Move from structure to browse to query without losing your place. Every panel is part of one focused terminal workflow.

The workbench

Schema
Browse tables, views, columns, types, indexes, and foreign keys.
Workspace
Keep query tabs, edit SQL or mongosh-style statements, and execute or cancel them asynchronously.
Structure
Inspect the fields and structure of the selected table or collection.
Browse
Explore records directly before writing a query.
Query log
Review executed statements and their outcomes.
Diagrams
See relationships between database objects when exposed by the backend.

Keybindings

KeyAction
F5Execute the current query.
Ctrl+EnterExecute the current query from the editor.
Ctrl+SSave the current workspace or query.
EscapeCancel a running query.

Results that stay useful

A failed or cancelled query retains the prior result table. Display output is capped at 500 rows, and each cell is capped at 300 runes.
